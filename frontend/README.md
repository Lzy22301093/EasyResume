# EasyResume Frontend

Vue 3 + TypeScript + Element Plus + Pinia。

产品介绍与在线预览见仓库根 [`README.md`](../README.md)；部署与使用说明见 [`docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md)。

```bash
# 本地开发（需 frontend/.env.local 设 VITE_API_TARGET=http://localhost:8000）
npm install
npm run dev

# 类型检查 + 构建（兼作前端验证）
npm run build
```
